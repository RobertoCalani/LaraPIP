Description:
Larapip is an interactive shell script that scaffolds a complete Docker-based Laravel development environment in under two minutes. Answer a few questions and get a production-like local setup with FrankenPHP, your choice of database, queues, HTTPS, and optional services — all containerized.

Additional Description:
Larapip (Laravel + Docker — Automated Development Environment) is a Bash-based interactive installer that generates a full Docker stack for Laravel development without requiring PHP, Composer, or Node.js on the host machine.

After answering 6 guided prompts, it produces docker-compose.yml, Dockerfile (FrankenPHP with extensions), Caddyfile, PHP configuration, and a larapip.sh launcher with convenience commands for containers, database shell, backups, and restores.

Key features:
- Interactive wizard in English and Spanish with input validation
- Support for Laravel 11 (EOL), 12, and 13 (latest)
- PHP versions 8.2, 8.3, and 8.4 via FrankenPHP (HTTP/2, Octane, worker mode)
- Database engines: MySQL 8.0, MariaDB 11, PostgreSQL 16, SQLite, and SQL Server 2022
- Optional services: Mailpit, Redis, phpMyAdmin, pgAdmin, Adminer, and MinIO
- SSL modes: none (HTTP), automatic self-signed certificates, and manual certificates
- Node.js versions 18, 20, and 22 with Vite Hot Module Replacement on port 5173
- Dedicated containers for task scheduler (schedule:work) and queue worker (queue:work)
- Port conflict detection before starting containers
- Automated database migrations after container startup
- Persistent Docker volumes for all database engines
- Bridge scripts (./artisan and ./composer) that run commands inside the app container
- Database backup and restore commands
- Automatic .env configuration and .env.example sync
- Port conflict detection
- Works on Linux, macOS, and Windows via WSL2
